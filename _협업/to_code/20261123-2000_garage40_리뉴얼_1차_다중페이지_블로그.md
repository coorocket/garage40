## 왜

지금 사이트는 `index.html` 1장이다. 잡을 수 있는 검색어가 1~2개뿐이고, 글을 계속 올릴 구조가 아니다.
사장님 결정(2026-11-19): 이름은 **폴리시40(POLISH40)**, 대표 문구는 **「덮지 않는 광택」**, 주 문의는 **문자 먼저**, 사이트 안에 **블로그**를 둔다.

이번 1차는 **지금 주소(garage40.netlify.app)에서** 새 구조를 올린다. 자체 도메인은 이번 주 안에 사서 붙이며, 그때 2차 요청서가 따로 온다. 그래서 **사이트 주소는 한 곳(`SITE_URL`)에만 적고** 나머지는 전부 거기서 만들어지게 한다.

## 할 일

### 1. 만드는 방식 바꾸기 (Astro, 정적 출력)

1. Astro 최신 안정판으로 정적 사이트를 만든다. 화면용 프레임워크(React 등)와 외부 CDN 글꼴·스크립트는 넣지 않는다. 외부 스크립트는 지금 있는 GA4 하나만 둔다.
2. 패키지 관리자는 pnpm 유지. `@openai/sites-vite-plugin`, `vite.config.js`, `server/`, `.openai/`는 쓰지 않으므로 지운다.
3. `netlify.toml`을 새로 만든다: 빌드 명령 `pnpm build`, 게시 폴더 `dist`, Node 22. (지금 Netlify는 저장소 루트를 그대로 게시한다. Aside가 Netlify 설정 화면은 확인하지 못했다. **PR의 deploy preview가 정상으로 뜨는지가 판정 기준**이다. 실패하면 멈추고 알린다.)
4. `src/data/site.ts` 한 파일에 사이트 공통 값을 모은다.
   - `SITE_URL = 'https://garage40.netlify.app'` (끝에 `/` 없음. 2차 때 이 한 줄만 바꾼다)
   - 이름 `폴리시40`, 영문 `POLISH40`, 사업자 표기·대표 이름·사업자등록번호·전화·메일·카카오 오픈채팅 주소·GA4 ID: **지금 `index.html`에 있는 값을 그대로 옮긴다** (이 요청서에는 적지 않는다)
   - 주소는 지금 값에서 끝의 `, 1F`만 ` 1층`으로 바꾼 표기, 운영 시간은 지금 값 그대로
   - 가격: 스탠다드 15만원부터, BEST 30만원부터, VIP 50만원부터
5. canonical, og:url, sitemap, rss, robots.txt의 Sitemap 줄, llms.txt, JSON-LD의 주소는 **모두 `SITE_URL`에서 만든다.** 코드 어디에도 `garage40.netlify.app`을 직접 적지 않는다(아래 6번 이동용 파일 1개만 예외).
6. GitHub Pages(저장소 루트를 그대로 게시 중)가 깨지지 않게 한다.
   - 루트에 `.nojekyll` 추가
   - 루트 `index.html`은 **이동 전용 한 장**으로 바꾼다: `<link rel="canonical">`과 즉시 이동(meta refresh + `location.replace`)이 `https://garage40.netlify.app/`을 가리킨다. 본문은 "폴리시40 사이트로 이동합니다" 링크 한 줄.
   - 이 파일이 Astro 개발 서버나 빌드에서 홈 화면을 가리면, 이 방법을 버리고 `to_aside/`에 알린다.
7. 루트에 있던 공개 파일은 `public/`으로 옮겨 **주소가 그대로** 나오게 한다: 검색엔진 확인 파일 2개(`google…html`, `naver…html`), IndexNow 키 파일(`74b1…txt`), `image/` 폴더(경로 `/image/…` 유지).
8. `_협업/`, `docs/`는 그대로 둔다(게시되지 않는다).

### 3. 글 넣는 구조 (글 1편 = 파일 1개)

1. `src/content/blog/*.md`: 머리말에 `title, description, category, keyword, pubDate, updatedDate, summary(답 먼저 문단), glance(한눈에 보기 표: 이름·값 목록), faq(질문·답 목록), related(관련 글·페이지 주소 목록), cover, coverAlt, masterNote, draft`. `cover`와 `masterNote`가 비어 있으면 그 칸을 화면에서 숨긴다.
2. `src/content/cases/*.md`: `title, car, color, symptom, program, hours, priceRange, area, before[], after[], process[], masterNote, steps[], result, limits, pubDate, draft`.
3. 글을 추가하면 목록, 홈의 "새 글 3편", `/rss.xml`, `/sitemap.xml`이 자동으로 따라오게 한다.
4. 글쓴이 줄은 "글 폴리시40 · 올린 날 · 고친 날"만 쓴다. "감수"라는 말은 쓰지 않는다(아직 감수를 받지 않았다).

### 4. 공통 부품 (원고의 [공통] 묶음)

머리말, 꼬리말, 사진 2장 진단 블록(`#diagnosis`), 가게 사실 카드, 3단계, 프로그램 표, 휴대폰 아래 고정 버튼을 부품 1개씩으로 만든다. 값은 `site.ts`에서 읽는다.

- 주 버튼 "사진 2장으로 진단 받기": 기본은 같은 페이지의 `#diagnosis`로 이동. 휴대폰 폭(720px 이하)에서는 문자 창을 바로 연다(본문에 어느 페이지에서 눌렀는지 한 줄 자동 기입).
- 진단 블록의 폼은 지금 `assets/site.js`의 동작(입력 → 문자 본문 조립, 카톡은 복사 안내, 서버 전송 없음)을 그대로 옮긴다. 차종 칸이 비어 있으면 보내기 전에 "차종을 적어 주세요"라고 알린다. 문자 제목 줄은 `[폴리시40 사진 2장 진단]`.
- 누르는 칸(버튼·링크)의 높이는 휴대폰에서 44px 이상.
- 글꼴: 웹폰트를 내려받지 않는다. `font-family`는 기기 글꼴 순서(Pretendard가 깔려 있으면 그것, 다음 Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic, sans-serif).
- 색과 분위기는 지금 `assets/styles.css`의 검정·아이보리·금빛을 그대로 쓴다. 한글 줄바꿈은 `word-break: keep-all`.

### 5. 측정 (지금 것 유지)

- GA4 코드와 `contact_click`(값: `method`, `page_type`, `page_path`, `cta_position`)을 모든 페이지에서 그대로 보낸다.
- `<body data-page-type="…">`은 2번 표의 값.
- `data-track` 값: `header_cta, hero_cta, mid_cta, price_cta, faq_cta, bottom_cta, form_submit, sticky_mobile, footer_cta`. 전화·문자·카톡 링크에는 빠짐없이 붙인다.

### 6. 검색엔진·AI용 파일

1. `/sitemap.xml`: **지금 주소 그대로 한 파일(urlset)**로 만든다(콘솔에 이 주소로 제출돼 있다. `sitemap-index.xml` 방식 금지). 2번 표의 15개 주소 + 공개된 사례. `lastmod`는 그 페이지나 글의 실제 수정일.
2. `/rss.xml`: 블로그와 사례 새 글.
3. `/robots.txt`: 전체 허용 + `Sitemap:` 줄. `Yeti`(네이버), `Googlebot`, `Bingbot`, `GPTBot`, `OAI-SearchBot`, `ChatGPT-User`, `ClaudeBot`, `PerplexityBot`, `Google-Extended`를 이름으로 적어 허용한다.
4. `/llms.txt`: 원고의 [llms] 묶음.
5. JSON-LD
   - 모든 페이지: `AutomotiveBusiness`(이름 `폴리시40`, `alternateName`: `POLISH40`, `GARAGE40`, 지금 값의 사업자 이름, 전화·주소·시간·메일은 지금 값, `image`, `areaServed`: 시흥·광명·부천·안산·안양·인천, `priceRange`)
   - 홈: `WebSite`(이름 `폴리시40`)
   - 홈 외 모든 페이지: `BreadcrumbList` (화면에도 "홈 › 자동차광택 › 광택 비용"처럼 보이게)
   - 서비스·가격 페이지: `Service` + 시작가 `Offer`(가격이 있는 것만)
   - FAQ가 화면에 보이는 페이지: `FAQPage` (화면의 질문·답과 글자가 같아야 한다)
   - 블로그 글: `BlogPosting`(글쓴이는 조직 `폴리시40`, 날짜)
6. og/twitter 태그는 페이지마다 제목·설명·주소가 맞게. 공유 그림은 지금 `image/og-garage40.png`를 그대로 쓴다(그림 교체는 다음에).

## 금지

- 원고에 없는 문장·숫자·후기·경력·자격을 만들어 넣지 않는다. 원고에 빠진 글이 있으면 비워 두고 `to_aside/`에 적는다.
- "최고, 1위, 100%, 완벽, 무조건" 같은 말, 다른 업체를 깎는 말 금지.
- 지금 사이트에 있던 다음 표현은 **새 사이트에 옮기지 않는다**(근거 확인 중): "24,000대", "대한민국 광택 1세대", "광택의 시초", "SINCE 1980", "100% AS", 영어 문구 전부.
- "덴트"를 하는 일로 적지 않는다.
- 2번 표 밖의 페이지 추가, 표의 주소·title·H1 변경 금지.
- `noindex`는 404에만. 다른 페이지에 넣지 않는다.
- 검색엔진 확인 파일, IndexNow 키 파일의 이름·내용 변경 금지.
- 요청서·결과 메모·커밋 메시지에 전화번호·실명·토큰을 적지 않는다.
- **push는 3번 이하로 모은다**(push마다 Netlify 미리보기가 돌아 무료 한도가 줄어든다). main 직접 push·병합 금지.

## 사전검토 표 (seo-change-guard)

| 항목 | 질문 | 판정 | 근거 |
|---|---|---|---|
| URL | 색인된 URL이 바뀌나 | 안전 | 색인된 페이지는 `/` 1개이고 그대로다. 새 주소 14개가 생긴다. 주소에 날짜 없음 |
| 삭제/404 | 기존 URL이 사라지나 | 낮은 위험 | 페이지 없음. `/assets/styles.css`, `/assets/site.js`와 그림 2장 주소가 없어진다(검색 대상 아님). `#packages` 같은 페이지 안 위치 링크는 없어진다 |
| 사이트맵 | 목록·lastmod | 낮은 위험 | `/sitemap.xml` 주소 유지, 1개 → 15개. lastmod는 실제 수정일 |
| 색인 지시 | robots, noindex, canonical | 낮은 위험 | canonical은 페이지마다 자기 주소(같은 호스트). robots.txt는 허용 범위 그대로에 로봇 이름만 적음. noindex는 404만 |
| 콘텐츠 | 얇은·복제 페이지 | 낮은 위험 | 하루 15페이지(상한 20 이하). 페이지마다 주제가 다름. `/wash/`, `/terms/`, `/privacy/`는 짧다 |
| title/meta | 제목 변경 | **위험(작음)** | 홈 title이 바뀐다. 앞머리 "자동차광택 비용 15만원부터"는 `/polish/price/`가 이어받고, 지역 5곳 나열은 빠진다. 지금 네이버 주 클릭 4, 구글 클릭 0(11월 초 기록)이라 잃을 양은 작다 |
| 안정성 | 빌드·호스팅 | **모름** | Netlify가 "루트 그대로"에서 "빌드 후 dist"로 바뀐다. 설정 화면을 확인하지 못해 preview 성공으로 판정한다. 실패 시 머지하지 않는다 |
| 네이버 영향 | 노출 중인 검색어 | 위험(작음) | "시흥 자동차광택" 화면에 지금 홈이 있다. 새 홈 title·H1에 "시흥 자동차광택"을 그대로 둔다 |
| 구글 영향 | 색인·스팸 | 안전 | 색인 1쪽. 지역만 바꾼 복제 페이지 없음 |
| 되돌리기 | 원복 | 안전 | PR 되돌리기 1번(이전 커밋 ff82fc3 상태). Netlify 이전 배포로 되돌리기도 가능 |
| 측정 | 지표·날짜 | 안전 | 머지 직후 Aside가 15개 주소 라이브 확인. 판정은 도메인 연결 뒤 6주 |

- 구글 SEO 부정 영향: 작다. 색인 1쪽, 클릭 0에서 시작한다. 다만 며칠 뒤 도메인을 옮기면 새 주소들이 한 번 더 바뀌므로, **새 페이지 색인 요청은 도메인 연결 뒤에만** 한다.
- 네이버 SEO 부정 영향: 작다. 홈 제목이 바뀌어 "자동차광택 비용" 쪽 노출이 잠시 흔들릴 수 있다. "시흥 자동차광택"은 제목·H1에 남긴다.
- URL 변경 위험: 지금 색인된 주소(`/`)는 그대로. 새 주소는 한 번 정하면 바꾸지 않는다. 도메인 연결 때 호스트만 바뀌고 경로는 같다.
