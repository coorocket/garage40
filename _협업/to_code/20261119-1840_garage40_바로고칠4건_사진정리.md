## 왜

리뉴얼(새 사이트)은 1월 공개 예정이라, 그 전에 지금 사이트에서 **사실과 다른 것**과 **눈에 띄는 오류**만 먼저 고친다.

- 하지 않는 작업(덴트)이 서비스로 적혀 있다. 사장님 확인(2026-10-19): 직접 하는 일은 광택, 유리막코팅, 손세차, 실내세차다.
- 서비스 03 사진이 필름을 벗기는 장면이라, 하지 않는 작업(PPF·랩핑)처럼 보인다.
- 휴대폰에서 첫 화면 문장이 "다듬습니다.대한민국"으로 붙어 보인다.
- 개인정보처리방침에 "입력 양식을 운영하지 않습니다"라고 적혀 있는데 견적 폼이 있다. 방문 통계(GA4) 안내도 없다.
- 저장소에 다른 업체 로고가 찍힌 사진이 있다. 화면에는 안 쓰지만 공개 주소로 열린다.

## 할 일

1. **방문 안내 서비스 줄 (index.html)**
   - 지금: `<dd>광택 · 유리막 코팅 · 실내세차 · 덴트</dd>`
   - 바꿈: `<dd>광택 · 유리막 코팅 · 손세차 · 실내세차</dd>`

2. **서비스 03 카드 사진 (index.html)**
   - 지금: `<img src="image/result-case3.webp" alt="조명으로 도장면의 스월 마크를 진단하는 차량" width="1200" height="800" ...>`
   - 바꿈: `src="image/problem-comparison.webp"`, `width="1400"`, `height="934"`. alt와 나머지 속성은 그대로.
   - `image/problem-comparison.webp`는 이미 저장소에 있고 같은 페이지 위쪽에서 쓰는 사진이다. 새 파일을 만들지 않는다.
   - `image/result-case3.webp` 파일 자체는 지우지 않는다(참조만 뺀다).
   - 카드 3장의 사진 높이가 전과 같게 보이는지 확인한다. 달라지면 CSS를 고치지 말고 멈춰서 알린다.

3. **첫 화면 소개 문장 띄어쓰기 (index.html)**
   - 지금: `다듬습니다.<br>대한민국 광택 1세대`
   - 바꿈: `다듬습니다. <br>대한민국 광택 1세대` (마침표 뒤에 빈칸 1개)
   - 이유: 휴대폰에서는 `<br>`이 숨겨져(`.hero-lead br { display: none; }`) 두 문장이 붙는다. 문구는 바꾸지 않는다.

4. **개인정보처리방침 창 (index.html, `#privacy-dialog`)**
   - 첫 문단
     - 지금: `GARAGE40 웹사이트는 회원가입 또는 별도의 개인정보 입력 양식을 운영하지 않습니다.`
     - 바꿈: `GARAGE40 웹사이트는 회원가입을 받지 않습니다. 견적 폼에 적은 내용은 서버로 전송되거나 저장되지 않고, 고객님 기기의 문자·카카오톡 작성 화면으로만 옮겨집니다.`
   - "2. 보유 및 파기" 다음에 새 항목 추가
     - `<h3>3. 방문 통계</h3><p>사이트 이용 현황을 파악하기 위해 Google Analytics(GA4)를 사용합니다. 이 과정에서 쿠키와 방문 기록(본 페이지, 누른 버튼)이 Google에 전송될 수 있으며, 이름과 연락처는 수집하지 않습니다.</p>`
   - 기존 "3. 문의"는 번호만 "4. 문의"로. 책임자 이름과 메일은 그대로 둔다.

5. **안 쓰는 사진 2장 삭제**
   - `image/intro-car-detail.webp` (다른 업체 로고와 SNS 띠가 찍혀 있음)
   - `image/intro-car-side.webp` (외국 번호판과 다른 업체 주소 글자가 보임)
   - 2026-11-19 확인: `index.html`, `assets/styles.css`, `assets/site.js` 어디에서도 두 파일을 부르지 않는다. 삭제 전에 저장소 전체에서 한 번 더 검색하고, 쓰는 곳이 나오면 지우지 말고 알린다.

## 사전검토 표 (seo-change-guard)

| 항목 | 질문 | 판정 | 근거 |
|---|---|---|---|
| URL | 색인된 URL이 바뀌나 | 안전 | 페이지 주소는 `/` 1개 그대로 |
| 삭제/404 | 기존 URL이 사라지나 | 낮은 위험 | 페이지는 없음. 안 쓰는 그림 주소 2개가 404가 된다. 이 2장이 이미지 검색에 잡혀 있는지는 확인하지 않았다 |
| 사이트맵 | URL 목록·lastmod가 바뀌나 | 안전 | 건드리지 않음 |
| 색인 지시 | robots, noindex, canonical 변경 | 안전 | 없음 |
| 콘텐츠 | 얇은·복제 페이지 추가 | 안전 | 페이지 추가 없음 |
| title/meta | 제목·설명 변경 | 안전 | 없음 |
| 안정성 | 느려지거나 오류 위험 | 안전 | 정적 파일, 사진 1장 참조 교체(같은 페이지에서 이미 불러오는 파일) |
| 네이버 영향 | 노출 중인 검색어 영향 | 낮은 위험 | 본문에서 "덴트" 낱말 1개가 빠진다. 덴트 검색 노출이 있었는지는 확인하지 않았다. 하지 않는 작업이라 빠지는 것이 맞다 |
| 구글 영향 | 색인·노출 페이지 영향 | 안전 | 색인 1쪽, 본문 소폭 수정 |
| 되돌리기 | 원복 방법 | 안전 | PR 되돌리기 1번. 삭제한 그림도 git 이력에 남는다 |
| 측정 | 효과 지표·날짜 | 해당 없음 | 사실 바로잡기라 효과 측정 대상이 아님. 머지 직후 Aside가 라이브 확인 |

- 구글 SEO 부정 영향: 없음으로 본다. 제목·설명·스키마·주소가 그대로다.
- 네이버 SEO 부정 영향: 거의 없음으로 본다. 본문 낱말 1개와 사진 1장만 바뀐다.
- URL 변경 위험: 페이지 주소 변화 없음. 안 쓰는 그림 주소 2개만 없어진다.
